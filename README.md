# Desarrollo de aplicaciones web

Repositorio para la materia de desarrollo de aplicaciones web.

## Descripción

Este repositorio reúne materiales, prácticas y ejemplos relacionados con la asignatura **Desarrollo de Aplicaciones Web**. Aquí se pueden encontrar recursos y ejercicios orientados al aprendizaje de tecnologías utilizadas en el desarrollo web, incluyendo **HTML**, **CSS**, **JavaScript** y **Python**.

## Contenido

- Ejercicios y prácticas de clase.
- Ejemplos de desarrollo frontend y backend.
- Archivos de apoyo para el aprendizaje de conceptos fundamentales de aplicaciones web.

## Objetivo

Servir como espacio de organización y consulta para el trabajo realizado durante la materia, facilitando el seguimiento de actividades y el acceso a los distintos recursos del curso.
